- 開發與維護 MES、PM、HR 系統，支援跨部門日常營運
- 建置 RESTful API 服務，實現前後端高效整合
- 導入 Docker 容器化部署，提升系統可維護性與擴展彈性
- 撰寫 Unit Test，確保程式品質與系統穩定性
- 落實 Git 版本控管，強化團隊協作效率

#### 工業電腦公司｜軟體工程師

**2024～2026**

主導企業內部系統之 Web 開發與架構設計，採用 ASP.NET Core MVC、Entity Framework Core 與 Vue.js 技術棧，整合 MSSQL 與 Oracle 雙資料源，支援跨部門營運需求。

- 規劃分層架構並導入 RBAC 權限控管，強化系統模組化與安全性
- 運用 EF Core 與 LINQ 處理複雜查詢邏輯，統一雙資料庫存取介面
- 建置 Vue.js + Axios 前端架構，實現即時資料串接與呈現
- 開發 Chart.js 資料視覺化儀表板，強化工廠端決策效率
- 獨立開發 ESOP、BPM 簽呈等系統，優化跨部門作業流程，有效降低人力成本

#### 科技業｜軟體工程師

負責企業級應用系統開發與維護，採用 Vue.js 與 .NET Core API 技術架構，支撐核心業務系統運作。
